# Anywear: Our Story page designs

Design work for the **Our Story** page of [anywearindia.com](https://anywearindia.com).

- `designs/`: the new modern designs (Aurora, Gallery, Noir)
- `temp/`: every earlier exploration (v01 to v27), kept for reference
- `index.html`: lists everything, newest first

Each design is a single, self-contained HTML file. Photos load from anywearindia.com and fonts from Google Fonts. The founder's name is a placeholder (`[Founder Name]`) until it is confirmed.
