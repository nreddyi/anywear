# Anywear: Our Story page designs

Design explorations for the **Our Story** page of [anywearindia.com](https://anywearindia.com).

- `index.html`: lists every version with a short description
- `designs/v01.html` … `designs/v20.html`: each design as a single, self-contained HTML file

The latest and recommended direction is **v20** (`designs/v20.html`).

Each page loads its photos from anywearindia.com and its fonts from Google Fonts. The founder's name is a placeholder (`[Founder Name]`) until it is confirmed.
